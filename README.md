
# CMOS Inverter Design and Analysis

## Project Overview
Design and simulation of a CMOS inverter using
PMOS and NMOS transistors.

## Objectives
- Understand CMOS inverter operation.
- Perform DC analysis.
- Study transient response.
- Analyze switching behavior and propagation delay.

## Tools Used
- LTspice
- CMOS Level 1 MOSFET models
- GitHub

## Circuit Parameters
- Supply voltage: 1.8 V
- NMOS width: 1 um
- PMOS width: 2 um
- Channel length: 180 nm
- Load capacitance: 10 fF

## Simulation Files
- cmos_inverter_dc.cir
- cmos_inverter_transient.cir

## Expected Observations
- Low input produces a high output.
- High input produces a low output.
- Transient output is inverted relative to the input.
